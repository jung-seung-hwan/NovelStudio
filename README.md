# Novel Studio

Unity 게임과 독립된 소설 연출 에디터 프로토타입. 이 폴더 안에서만 작업합니다.

## 실행

Node.js 20 이상에서 `Start.cmd`를 실행하고 http://127.0.0.1:4173 을 여세요. 또는 이 폴더에서 `node server.mjs`를 실행하세요. 서버를 종료하려면 터미널에서 Ctrl+C를 누릅니다. 패키지 설치는 필요하지 않습니다.

## 사용

1. 새 회차를 추가하고 텍스트를 입력하거나 UTF-8 TXT를 가져옵니다. 빈 줄이 장면 구분입니다.
2. 인물 탭에서 이름, 별칭, 설명, 기술을 등록합니다.
3. 원문 탭에서 장면 분석을 실행합니다. 장면 연출 탭에서 인물, 감정, 상태, 기술을 수정합니다.
4. 이미지 보관함에서 인물별 기본/감정 이미지와 배경을 등록합니다. 배경은 장면 설정에서 선택합니다.
5. 읽기 모드에서 문단을 선택하거나 화살표 버튼/키로 장면을 넘깁니다.
6. 프로젝트 내보내기로 이미지까지 포함한 JSON 백업을 저장합니다.

데이터는 사이트 주소별 브라우저 IndexedDB에 자동 저장됩니다. 서버나 계정에 동기화되지 않으므로 다른 주소/기기에서는 JSON을 내보내고 불러와야 합니다. 폰트만 Google Fonts에서 로드하며 실패해도 시스템 글꼴로 동작합니다.

## 현재 범위

- 샘플 작품에는 내장 image_gen으로 만든 이미지 6장이 자동 연결됩니다. 유나 기본/기쁨/분노·불꽃 검격, 시온 기본/두려움·부상, 안개 숲 배경입니다. 원본은 `dist/assets`에 있고 생성 프롬프트는 `dist/assets/prompts.txt`에 있습니다.
- 기존 샘플 원문과 일치하는 회차에만 이미지 팩을 한 번 적용합니다. 직접 올린 동일 인물·감정 이미지와 선택한 배경은 유지됩니다. 다른 작품에는 자동 추가하지 않으며 이미지 보관함에서 파일을 직접 업로드할 수 있습니다.

- JavaScript ES modules로 만든 설치 없는 첫 프로토타입입니다. 프레임워크/TypeScript 전환 전에 편집 흐름을 검증하기 위한 구성입니다.
- AI 모델은 아직 연결하지 않았습니다. 등록 이름/별칭과 감정 키워드로 초안을 만들며, 이름 후보는 조사 패턴으로 추정합니다. 인물 후보와 기술은 사람이 검토/등록합니다.
- 한 장면의 대표 인물 한 명을 표시합니다. 다인물 감정 추론, 자동 스크롤 동기화, 회차별 설정 이력, 기술 효과 애니메이션은 후속 범위입니다.
- 재분석 시 원문이 정확히 같은 장면의 ID와 수동 설정을 유지합니다. 원문이 바뀐 장면은 새 초안을 만듭니다.
- 인물/이미지는 작품 공통 자산입니다. 읽기 화면은 장면별 기술/상태만 표시하며 인물 도감 전체를 노출하지 않습니다.
- API 키, 플랫폼 스크래핑, 외부 소설 서비스 연동은 포함하지 않습니다.

## 검증

`node --test tests/engine.test.mjs`

`node --check dist/app.js`

`dist/engine.js`는 추출·재분석·이미지 대체·프로젝트 검증을 담당합니다. `dist/app.js`는 UI와 IndexedDB 저장을 담당합니다. `server.mjs`는 로컬 정적 서버입니다.
